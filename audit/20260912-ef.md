### 고친 방식 — 하드코딩 삭제가 아니라 조건부

`public/js/app.js` 에 판정 헬퍼 하나를 두고 두 자리에서 같이 쓴다:

```js
function hasDamage(participants) {
    return (participants || []).some(function (p) { return Number(p.damage) > 0; });
}
```

- **매치 카드**: `hasDamage(entry.participants)` 가 false 면 `.match-dmg`(`🗡 N`) 줄 자체를 안 만든다.
  판정 기준을 `me.damage` 가 아니라 **그 경기 참가자 8명 전체**로 잡았다 — 초반에 터져 진짜로 0딜인 사람 한 명 때문에 살아 있는 수치가 사라지면 안 된다.
- **상세 표**: `showDmg` 가 false 면 `<th class="num">딜량</th>` 과 각 행의 `<td class="detail-num">` 을 **둘 다** 빼 열을 통째로 없앤다. CSS `display:none` 이 아니라 마크업에서 빠지므로 th/td 개수가 항상 맞는다.
- `.detail-table` 에 `nth-child` 규칙이 없어(폰 열 숨김은 `.rank-table` 쪽만 쓴다) 열 하나가 빠져도 다른 규칙이 어긋나지 않는다.

**되살아나는지 실증** — `server/api.js` 의 `damage` 를 임시로 `(9 - placement) * 1234` 로 바꿔 띄워 보니 **프런트를 한 줄도 안 고친 채** 열과 아이콘이 그대로 돌아왔다:

```
{"th":["순위","소환사","레벨","라운드","딜량","덱"], "thCount":6, "tdCount":6,
 "firstRowCells":["#1","jjames#prac","Lv 9","6-3","9,872", ...],
 "dmgEls":10, "dmgText":["🗡 9,872","🗡 9,872","🗡 4,936"]}
```

임시 패치는 확인 직후 `git checkout -- server/api.js` 로 되돌렸고, 커밋에는 안 들어간다. 라이엇이 값을 채우기 시작하면 배포 없이 저절로 복구된다.
